# 🍽️ Gerenciador de Receitas com .NET

Este projeto é parte de um curso prático e avançado com foco em desenvolvimento backend com .NET. Trata-se de uma API moderna e escalável para gerenciar receitas de cozinha, integrando autenticação via Google, sugestões com base em inteligência artificial (ChatGPT) e diversas boas práticas de desenvolvimento profissional.

---

## 🚀 Tecnologias Utilizadas

- **.NET 7 / .NET 8**
- **C#**
- **Entity Framework Core**
- **Azure DevOps + CI/CD Pipelines**
- **Docker**
- **JWT + Refresh Token**
- **Google OAuth**
- **ChatGPT API**
- **FluentValidation**
- **Mensageria (RabbitMQ)**
- **SonarCloud / SonarQube**
- **Injeção de Dependência**
- **Migrations**
- **SCRUM**
- **Git e GitFlow**
- **Clean Code**
- **Testes de Unidade e Integração**

---

## 🧠 Conceitos e Práticas

- **Domain-Driven Design (DDD)**
- **Arquitetura em camadas (API, Application, Domain, Infrastructure, Communication, Exceptions)**
- **Princípios SOLID**
- **Boas práticas de versionamento e controle de código**
- **Publicação no Azure com pipelines automatizados**
- **CI/CD completo com validações, testes e deploy contínuo**

---

## 📌 Funcionalidades

- 📋 Cadastro, visualização, edição e exclusão de receitas
- 🔍 Filtros inteligentes por ingredientes, categorias e nome
- 📷 Upload de fotos das receitas
- 🔐 Autenticação via **Google OAuth**
- 🤖 Sugestão de receitas usando **ChatGPT**
- 🛠️ Dashboard de qualidade de código com **SonarCloud**
- 🔁 Testes unitários e de integração automatizados
